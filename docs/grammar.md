# Граматика SIPL

Граматика реалізована за допомогою Lark на основі
БНФ мови SIPL з навчального посібника
«Теорія програмування. Практикум».

## Лексика

Ключові слова: begin, end, if, then, else, while, do, skip.

Імена змінних починаються з латинської літери та можуть
містити латинські літери, цифри й символ підкреслення.

Числа: цілі додатні та від'ємні числа, а також нуль.

Арифметичні операції: +, -, *.
Операції порівняння: =, >.
Логічні операції: ∨, ¬.
Присвоювання: :=.
Роздільник операторів: ;.

## Пріоритети операцій

Від найвищого до найнижчого:

1. Множення.
2. Додавання та віднімання.
3. Порівняння.
4. Заперечення.
5. Диз'юнкція.
6. Присвоювання.
7. Цикл.
8. Розгалуження.
9. Послідовне виконання.

Бінарні операції лівоасоціативні.

## Коректна програма

    begin
        X := 5;
        Y := X + 2
    end

## Некоректна програма

    begin
        X = 5
    end

Для присвоювання необхідно використовувати :=.
