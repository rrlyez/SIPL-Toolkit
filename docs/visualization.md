# Візуалізація дерев

Модуль підтримує побудову дерева синтаксичного виводу
та абстрактного синтаксичного дерева SIPL-програми.

Дерево синтаксичного виводу містить синтаксичні
правила та термінальні символи.

AST містить основні конструкції програми,
необхідні для її виконання.

Кожен вузол зберігає позицію у вихідному коді.

## Формати експорту

- TXT — текстове представлення дерева.
- JSON — структуроване представлення.
- DOT — представлення у форматі Graphviz.
- HTML — порівняння Parse Tree та AST.

## Запуск

    python -m sipl.cli visualize examples/power.sipl

Результати зберігаються в папці output.

Файл comparison.html відкривається у браузері.
При наведенні на вузол відображається відповідний
фрагмент вихідного коду.

Для вибору іншої папки використовується
параметр --output.
